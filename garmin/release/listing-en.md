# Strength Save

## Short description

Log strength workouts from your wrist with today's plan, quick workouts, rest timers, and FIT recording.

## Description

Strength Save for Garmin is a standalone client for your Strength Save account. After one-time pairing, it downloads today's plan, supports planned or quick workouts, and syncs one canonical history visible on web, iOS, and Android.

- set targets and four exercise tracking types;
- default 90-second between-set and 150-second between-exercise rest timers;
- session duration, completed sets, and training volume;
- kilograms or pounds for display, with canonical storage in kg;
- offline queue, explicit sync state, retry, and safe session discard;
- native FIT activity with heart rate in Garmin Connect;
- Polish and English.

One active Strength Save PRO entitlement covers web, iOS, Android, Apple Watch, and Garmin. The watch has no separate purchase or paywall. Purchases and restores are available only in the iOS or Android app.

## Permissions

- **Communications** — encrypted plan download and batched event upload to the Strength Save backend.
- **Fit** — start and save a completed workout as a FIT activity in Garmin Connect.
- **Sensor** — read heart rate during an active workout for the FIT record.
- **UserProfile** — use profile and unit preferences needed for correct display and activity recording.

## Privacy

The watch stores only a minimal revocable device token, today's plan, and unsent events locally. It never stores a password or Firebase token. Workout data reaches the user's account only after durable backend acknowledgement. Privacy policy: https://strengthsave.app/legal/privacy.html
