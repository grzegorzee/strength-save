# Screenshot provenance

Screenshots in this directory come from the official Connect IQ 9.2.0
simulator and the signed release source. They use an unpaired, local simulator
state; no private account was used and no workout was finalized. Final listing
screenshots with a populated plan must be repeated on the isolated Store review
account before submission.

- `fr255-pairing-round.png`: round MIP, buttons only.
- `venusq2-pairing-rectangle.png`: rectangular AMOLED, touch + buttons.
