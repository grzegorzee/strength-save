**Goal:** Podsumowanie treningu z jedną dominującą liczbą (tonaż), PR-y zawsze z deltą, haptyka przy live PR, confetti zarezerwowane dla rzadkich momentów, zero zduplikowanych metryk.

Zero nowych zależności, zero zmian w modelu danych.

**Tech Stack:** React 18 + TS, lucide-react, istniejące `src/lib/haptics.ts`, vitest + RTL.

## Global Constraints

- `PRComparison` (`src/lib/pr-utils.ts:169`): `{ exerciseId, exerciseName, type: 'weight'|'1rm'|'both'|'reps'|'duration'|'weight_distance'|'effective_load', newValue, oldValue }` — NIE zmieniamy tego typu.
- Ekran treningu = strefa chroniona: żadnych nowych elementów w trakcie logowania serii poza istniejącym badge/toast.

- `prefers-reduced-motion` respektowane (ConfettiBurst już to robi — nie zepsuć).

```ts
/** Delta rekordu do wyświetlenia ("+5 kg" / "+2 powt.") albo null (brak sensownej bazy). */
export const formatPRDelta = (
  pr: PRComparison,
  fmtWeight: (kg: number) => string,
): string | null => {
  if (pr.oldValue <= 0 || pr.newValue <= pr.oldValue) return null;
  const diff = Math.round((pr.newValue - pr.oldValue) * 10) / 10;
  if (pr.type === 'reps') return `+${diff}`;
  if (pr.type === 'duration') return `+${Math.round(diff)}s`;
  return `+${fmtWeight(diff)}`;
};
```

`AutoAdvance` jako mikrokomponent w tym samym pliku:

```tsx
const AutoAdvance = ({ ms, onDone }: { ms: number; onDone: () => void }) => {
  useEffect(() => {
    const id = setTimeout(onDone, ms);
    return () => clearTimeout(id);
  }, [ms, onDone]);
  return null;
};
```
